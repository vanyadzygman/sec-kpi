# sec-kpi: Software requirements labs

Репозиторій лабораторних робіт з курсу «Моделювання та аналіз вимог до ПЗ».

Домен у всіх роботах один: спортзал (клієнти, тренери, заняття, абонементи, записи).

## Лабораторні роботи

Кожна робота лежить у власній гілці, створеній від `main`:

| Робота | Гілка               | Тема                                              |
| ------ | ------------------- | ------------------------------------------------- |
| Lab 1  | `lab1-er-model`     | Домен і модель даних (ER, Mermaid)                |
| Lab 2  | `lab2-requirements` | Вимоги та Use Cases (EARS, user stories, Gherkin) |
| Lab 3  | `lab3-sequence`     | Взаємодія (Sequence Diagram, Mermaid)             |

## Структура

```
sec-kpi/
├── lab1/                ← Lab 1 (гілка lab1-er-model)
├── lab2/                ← Lab 2 (гілка lab2-requirements)
├── lab3/                ← Lab 3 (гілка lab3-sequence)
├── LICENSE
└── README.md
```
