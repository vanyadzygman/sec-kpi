# User stories

| id    | історія                                                                                                            | REQ                            |
| ----- | ------------------------------------------------------------------------------------------------------------------ | ------------------------------ |
| US-01 | Як `Client`, я хочу зареєструватися в системі, щоб купувати абонементи й записуватися на заняття.                  | REQ-01, REQ-02                 |
| US-02 | Як `Client`, я хочу переглянути розклад занять із вільними місцями, щоб обрати заняття, на яке ще можна потрапити. | REQ-03, REQ-20                 |
| US-03 | Як `Client`, я хочу записатися на заняття, щоб прийти на тренування з тренером.                                    | REQ-04, REQ-05, REQ-06, REQ-07 |
| US-04 | Як `Client`, я хочу скасувати свій запис, щоб звільнити місце, якщо не зможу прийти.                               | REQ-08                         |
| US-05 | Як `Client`, я хочу купити абонемент, щоб мати право записуватися на заняття протягом оплаченого періоду.          | REQ-09, REQ-10, REQ-11, REQ-19 |
| US-06 | Як `Client`, я хочу отримати лист-підтвердження про запис чи купівлю, щоб мати підтвердження своїх дій.            | REQ-12, REQ-13, REQ-14         |
| US-07 | Як `Administrator`, я хочу створити заняття з тренером і місткістю, щоб клієнти могли на нього записатися.         | REQ-15, REQ-16                 |
| US-08 | Як `Administrator`, я хочу створити тип абонемента з назвою, тривалістю й ціною, щоб клієнти мали що купувати.     | REQ-19                         |
| US-09 | Як `Trainer`, я хочу побачити, хто записаний на моє заняття, щоб підготуватися до групи.                           | REQ-17                         |
| US-10 | Як `Administrator`, я хочу побачити, хто записаний на заняття, щоб контролювати заповненість груп.                 | REQ-17                         |
| US-11 | Як `Trainer`, я хочу відмітити, хто прийшов на заняття, щоб зберігати облік відвідування.                          | REQ-18                         |
