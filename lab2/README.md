# Lab 2: Requirements and Use Cases

Domain: **Gym** (same as in Lab 1, branch `lab1-er-model`)

## Description:

Structured requirements for the gym system: EARS requirements, user stories, use cases, Gherkin scenarios and a traceability matrix. All requirements use entity and field names from the Lab 1 ER model.

## Files:

- `spec.md`: intent, actors, definitions and acceptance criteria
- `requirements/`: EARS requirements, user stories, use cases
- `adr/`: architecture decision records (MADR)
- `ai/`: AI prompts and raw AI responses
